## 🚀 Fitur Utama

### 🧠 **Multi-Strategy Engine**
- **AI Trend Following** (EUR/USD) - Groq LLM untuk analisis market
- **Fibonacci 78.6% High Probability** (XAU/USD) - Fokus level golden zone
- **Dual Timeframe Analysis** - Scalping (M15+M5) & Intraday (H1+M15)

### 📊 **Teknikal Analysis**
- Fibonacci Retracement (61.8% & 78.6%)
- Support & Resistance (Swing High/Low)
- RSI, MACD, Bollinger Bands, Stochastic
- Candlestick Pattern Recognition (Pinbar, Engulfing, Marubozu)
- SMA 50 Trend Filter

### ⚙️ **Risk Management**
- Confidence-based entry filtering (≥85%)
- Fixed Risk:Reward Ratio 1:2
- Max position limits per symbol
- Spread & drawdown protection
- Daily loss limit

### 🔬 **Backtesting Engine**
- Multi-timeframe historical simulation
- Performance metrics (Win Rate, Profit Factor, Max DD)
- Monthly breakdown analysis
- CSV export untuk analisis lanjutan
